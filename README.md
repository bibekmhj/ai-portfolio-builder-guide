## 📋 Step-by-Step Guide

### Step 1: Sign Up for Claude (5 min)
1. Go to [claude.ai](https://claude.ai)
2. Create a free account
3. Verify your email

### Step 2: Generate Your Portfolio (10 min)
1. Start a new Claude conversation
2. Click the paperclip icon and **upload your resume**
3. Copy and paste the prompt below 👇

### Step 3: Save Your File (2 min)
1. Copy all the HTML code Claude generates
2. Open Notepad (Windows) or TextEdit (Mac)
3. Paste the code
4. Save as **`index.html`**

### Step 4: Deploy to Netlify (5 min)
1. Go to [netlify.com](https://netlify.com) and sign up free
2. Click **"Add new site"** → **"Deploy manually"**
3. Drag and drop your `index.html` file
4. Your site is live! 🎉

### Step 5: Customize Your URL (3 min)
1. In Netlify dashboard → Site configuration → Change site name
2. Set it to `yourname` or `yourname-portfolio`
3. Your URL becomes: `https://yourname.netlify.app`

## 🔑 The Master Prompt

Copy this prompt exactly into Claude after uploading your resume:

```
I've attached my resume. Please build me a complete, professional 
portfolio website as a single HTML file.

Requirements:
- Modern, clean design with a professional color scheme
- Fully mobile-responsive (works on phones and laptops)
- Sections: Hero/About, Skills, Work Experience, Projects, Education, Contact
- Smooth scrolling navigation
- My name prominently displayed
- A contact section with my email and LinkedIn
- Professional typography and spacing
- All CSS included in the same file (no external dependencies)

Please generate the complete HTML file ready to deploy.
```

## 🎨 Customization Prompts

After your first version is generated, use these prompts to customize:

**Change the color scheme:**
```
Change the color scheme to navy blue and white with gold accents
```

**Add a new section:**
```
Add a Certifications section after the Skills section
```

**Make it more creative:**
```
Make the design more creative and modern with card-based layouts
```

**Add animations:**
```
Add subtle fade-in animations when sections scroll into view
```

**Change the style:**
```
Make the design minimal and clean, inspired by Apple's website style
```

**Make it field-specific (non-CS students):**
```
Redesign this portfolio for a Business/Psychology/Design/Marketing 
student — adjust the sections and language accordingly
```
